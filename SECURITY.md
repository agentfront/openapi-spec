# Security Policy

`openapi-spec` reads OpenAPI documents, including documents you may not fully
trust. Security reports are taken seriously and handled with priority.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅ (from 1.0.0, the first release) |
| 0.0.1   | ❌ (name placeholder, exports nothing) |

## Reporting a vulnerability

**Please do not open a public issue for security reports.**

Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/agentfront/openapi-spec/security/advisories/new)
(preferred), or by email to **info@agentfront.dev** with the subject
`[SECURITY] openapi-spec`.

Please include:

- A description of the vulnerability and its impact
- A minimal reproduction (document snippet, code, or PoC)
- The affected version(s)

You can expect an acknowledgment within **3 business days** and a triage
verdict within **7 business days**. Confirmed vulnerabilities are fixed in a
patch release with a GitHub advisory (and CVE where applicable) crediting the
reporter, unless anonymity is requested. Please give us reasonable time to
release a fix before public disclosure.
